# Проект по банковским операциям "Credit Card Project"

## Описание проекта
Проект предназначен для обработки банковских транзакциях.

## Структура проекта:

** "src/" - исходный код проекта.
 * "masks.py" - функция для маскировки номера карты и счета.
 * "widget.py" -функция для работы с датами и типами карт
 * "processing.py" -функция фильтрации и сортировки списков транзакций

** "tests/" - папка с тестами.
 * "conftest.py"
 * "test_mask.py", "test_processing.py", "test_widget.py" - набор тестов для проверки соответствующих файлов.
 * "README.md" - файл с описанием проекта.
 * ".gitignore" - файл с игнорируемыми файлами для Git.

## Установка.

1. Клонировать репозиторий.
2. Установить зависимость через "Poetry":
 ```bash poetry install
   ```

## Тестирование

Для проверки кода используется фреймворк "Pytest".

### Для запуска тестов:

```bash pytest
```

### Отчет о процентном покрытии тестов:

```bash pytest --cov=src --cov-report=term-missing
```

## Декораторы

Добавлен модуль `decorators.py` с универсальным декоратором `@log`:
- **Логирование выполнения**: регистрирует начало и конец работы функций, а также возвращаемые результаты.
- **Гибкий вывод**: поддерживает необязательный аргумент `filename`. При его наличии логи записываются в указанный файл, при отсутствии — выводятся в консоль.
- **Перехват и регистрация ошибок**: если выполнение функции завершилось сбоем, декоратор фиксирует тип возникшего исключения и все переданные входные параметры.
