# Проект по банковским операциям 

Приложение для фильтрации, сортировки и маскировки данных банковских транзакций. 
Проект включает в себя логику обработки номеров карт/счетов и форматирования дат.

## Основной функционал
*   **Маскировка данных:** Безопасное отображение номеров карт и счетов (файлы `mask.py`, `widget.py`).
*   **Обработка транзакций:** Сортировка и фильтрация операций по дате и статусу (файл `processing.py`).
*   **Форматирование:** Преобразование дат в читаемый формат `ДД.ММ.ГГГГ`.

## Технологический стек
*   **Язык:** Python 3.12+
*   **Менеджер зависимостей:** Poetry
*   **Контроль качества кода:**
    *   `mypy` — статическая типизация.
    *   `black`, `autopep8` — форматирование кода.
    *   `flake8` — линтинг.
    *   `isort` — сортировка импортов.

## Установка

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com
    cd название-проекта
    ```

2.  **Установите зависимости через Poetry:**
    ```bash
    poetry install
    ```
    *Это создаст виртуальное окружение и установит все необходимые пакеты, включая инструменты разработки (dev/lint).*
