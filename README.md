# Проект по банковским операциям "Credit Card Project"

## Описание проекта
Проект предназначен для обработки банковских транзакциях.

## Структура проекта:

** "src/" - исходный код проекта.
 * "masks.py" - функция для маскировки номера карты и счета.
 * "widget.py" -функция для работы с датами и типами карт
 * "processing.py" -функция фильтрации и сортировки списков транзакций
 * "utils.py" - функции чтения транзакций из JSON, CSV и XLSX-файлов, а также функции фильтрации и аналитики операций.

 * "external_api.py" - функция конвертации валют через API.

** "tests/" - папка с тестами.
 * "conftest.py"
 * "test_mask.py", "test_processing.py", "test_widget.py" - набор тестов для проверки соответствующих файлов.
 * "test_utils.py", "test_external_api.py" - тесты для проверки новых модулей.
 * "README.md" - файл с описанием проекта.
 * ".gitignore" - файл с игнорируемыми файлами для Git.

## Установка.

1. Клонировать репозиторий.
2. Установить зависимость через "Poetry":
 ```bash 
 poetry install
 ```

## Тестирование

Для проверки кода используется фреймворк "Pytest".

### Для запуска тестов:

```bash 
poetry run pytest
```

### Отчет о процентном покрытии тестов:

```bash 
poetry run pytest --cov=src --cov-report=term-missing
```

### Проверка типов данных:

```bash
poetry run mypy src
```

## Декораторы

Добавлен модуль `decorators.py` с универсальным декоратором `@log`:
- **Логирование выполнения**: регистрирует начало и конец работы функций, а также возвращаемые результаты.
- **Гибкий вывод**: поддерживает необязательный аргумент `filename`. При его наличии логи записываются в указанный файл, при отсутствии — выводятся в консоль.
- **Перехват и регистрация ошибок**: если выполнение функции завершилось сбоем, декоратор фиксирует тип возникшего исключения и все переданные входные параметры.

## Покрытие тестами (HTML-отчет)
Проект протестирован с помощью `pytest`. Сгенерирован подробный отчет о покрытии функционального кода в формате HTML, который находится в папке `htmlcov/`.

* **Поддержка различных форматов данных:** Реализовано чтение финансовых операций не только из JSON-файлов, но и из табличных форматов **CSV** и **XLSX (Excel)** с автоматическим приведением данных к единому стандарту.
* **Логирование операций:** Все процессы чтения (успешное выполнение, отсутствие файлов или повреждение структуры) автоматически регистрируются в лог-файле `logs/utils.log`.

## Использование новых инструментов утилит

В модуле `utils.py` теперь доступны функции для поиска и подсчета операций:

* **Поиск по описанию (`process_bank_search`)**: ищет транзакции по ключевым словам с помощью регулярных выражений (без учета регистра букв).
* **Аналитика категорий (`process_bank_operations`)**: группирует операции по списку категорий и возвращает количество транзакций для каждой из них.

### Примеры:
```python
from src.utils import process_bank_search, process_bank_operations

data = [
    {"id": 1, "description": "Перевод организации"},
    {"id": 2, "description": "Оплата мобильной связи"},
    {"id": 3, "description": "Перевод другу"}
]

# Поиск операций со словом "перевод"
print(process_bank_search(data, "перевод"))

# Подсчет операций по категориям
print(process_bank_operations(data, ["Перевод", "Оплата"]))
```
